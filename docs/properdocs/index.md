# ProperDocs

Project documentation with&nbsp;Markdown.

---

ProperDocs is a **fast**, **simple** and **downright gorgeous** static site
generator that's geared towards building project documentation. Documentation
source files are written in Markdown, and configured with a single YAML
configuration file. Start by reading the [introductory tutorial], then check the
[User Guide] for more information.

## Features

### Great themes available

There's a stack of good looking [themes](user-guide/choosing-your-theme.md) available for ProperDocs. Choose between the official themes: [mkdocs](user-guide/choosing-your-theme.md#theme-mkdocs) and [readthedocs](user-guide/choosing-your-theme.md#readthedocs), select one of the third-party themes (on the [ProperDocs Catalog](https://github.com/properdocs/catalog#-theming)), or [build your own](dev-guide/themes.md).

### Easy to customize

Get your project documentation looking just the way you want it by [customizing your theme](user-guide/customizing-your-theme.md) and/or installing some [plugins](user-guide/configuration.md#plugins). Modify Markdown's behavior with [Markdown extensions](user-guide/configuration.md#markdown_extensions). Many [configuration options](user-guide/configuration.md) are available.

### Preview your site as you work

The built-in dev-server allows you to preview your documentation as you're writing it. It will even auto-reload and refresh your browser whenever you save your changes.

### Host anywhere

ProperDocs builds completely static HTML sites that you can host on GitHub Pages, Amazon S3, or [anywhere](user-guide/deploying-your-docs.md) else you choose.
