<H1 style="text-align: center;"> Set Up For Development</H1>

!!! desc "Set Up For Development"

    Note that working on this project requires the GNOME shell, the GNU gettext utilities, and npm.
    
    If you are just translating you can use any text editor or a specialized translation editor.
    
    If you want to write code then preferably use an editor that supports TypeScript/LSPs like VS Code, Neovim, or Emacs.
